    链接、设备镜像与 Runtime 装载

    LLVM Dialect 与 LLVM IR 是相邻的不同表示。MLIR Lowering 生成 LLVM Dialect，再导出 LLVM IR。最终指令选择、寄存器分配和链接由匹配版本的 VOLT / LLVM 工具链完成。

    Runtime 执行的是已编译好的 Dispatch DAG

    1. 分配设备程序、进程内常驻权重和中间张量 arena，绑定输入 / 输出地址。
    2. 上传本帧输入与调用方提供的历史状态，构造 Kernel 参数缓冲区。
    3. 按依赖顺序提交 Dispatch；写入完成后，消费者才能读取同一 Buffer。
    4. 等待设备完成并读回所需输出。调用方将 next_bev 作为下一帧 prev_bev，显式完成历史状态回馈。

    阶段报告是可检查的编译产物；生成源码、通过 MLIR 验证、生成设备镜像、设备运行是不同完成条件。性能数值应来自对应设备和输入规模的实际测量。
