01 共享 · 语义

GAC 语义层：类型、shape、属性校验

算子只声明“语义”，不执行计算。每个 Operation 的 verify() 和 ShapeInferencePass 都调用同一个 inferOperation()：已知维度必须一致，动态维度可以保留， 无法证明的语义直接报错。DCNv2 和 MSDeformAttn 使用独立的固定契约推导。

02 图优化 · 合法化

03 分叉判定

规则算子？→ isRegular()

这是整个 lowering 的唯一分叉点。只有 16 个算子被认定为“规则”，改写成结构化 Linalg； 其余算子保留 gac.*，交给专用发射器。规则算子如果形态不合法， 会直接报错，不会静默退回旧标量路径。

09 Runtime

manifest 驱动的执行

Runtime 不实现任何算子。它读取并重新校验 plan.json，分配/上传输入， 按 dispatch 顺序提交 Kernel，最后下载输出。Triton 与 native Kernel 共用同一张 dispatch DAG 和同一份静态 Buffer 规划。
