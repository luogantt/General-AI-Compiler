先看分块，再看搬运和计算

A、B 都是 4×4；每块是 2×2。这里逐轮算出 C 的左上角块 C00，再把这一块写回 DDR。

① 分块：每个框里的 4 个数字就是一个 2×2 Tile

以下框线标出 DDR 中的行列范围；完整矩阵仍按原来的行步长存放。粗边框标出计算 C00 需要的块。

DDR 中的 A · 4×4行 M ↓，列 K →
DDR 中的 B · 4×4行 K ↓，列 N →
DDR 中的 C · 4×4行 M ↓，列 N →

C00 = A00 × B00 + A01 × B10。A 取上面一行块，B 取左边一列块，沿共同的 K 轴分两轮相乘、累加。C00 是一个 2×2 块；C[0,0] 才是块里的一个元素。

本图只演示 C00。C01、C10、C11 分别用对应的 A 块行和 B 块列，重复同样的两轮计算，才能得到完整 C。

编译器 / VOLT

决定 tile、地址公式、stage 布局、指令与同步顺序。

Runtime / KMU

提供 DDR 基址，启动 CTA，并为 CTA 分配 LMEM SRAM 地址。

RTL 数据通路

DXA、Cache、LMEM banks、Barrier、LSU、GPR 与 FPU 执行这些指令。

实现边界：当前 sgemm2_dxa 用 C++ 手工写出 tile、双 Buffer 和调度；GAC/MLIR 的目标是自动产生同一份执行合同。Vortex RTL 提供通用外部存储接口，板卡可连接 DDR、GDDR 或 HBM。
