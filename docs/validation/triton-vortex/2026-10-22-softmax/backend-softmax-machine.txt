SIMT control-flow invariant
  The explicit split receives the original per-lane leader predicate.
  Only the guard branch after split receives llvm.riscv.vx.uniform.
  Every inspected softmax_f32 symbol contains exactly one vx_split and one
  matching vx_join; both use token register s2.
  The validation harness also reads the final LLVM IR for every executing
  positive case and asserts exactly one split call and one join call.
