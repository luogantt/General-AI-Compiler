MLIR 如何把一个程序，变成另一个程序？

只追踪一个例子：(x + 0) + y。看清输入、内存结构、变换和输出，再沿箭头找到实现它们的源码。

MLIR 的工作对象是“程序的表示”。它读取、保存和改写程序；此处不会计算运行时的 x、y。

方言定义“某个操作是什么意思”；公共框架负责保存、遍历、分派和改写。下面显示的是编译期 C++ 调用。

换一种方言，哪些东西复用？

这些方言可以同时出现在一个 Module 中。它们共享基础设施，具体的合法性、数学语义和转换规则仍需要各自实现。

具体操作 / 规则接到公共机制的关系源码
arith.addi
整数加法		Operation::fold → 注册的钩子 → AddIOp::fold；通用 Rewriter 应用替换。
scf.for
结构化循环		循环也是 Operation；循环体放在 Region / Block 中，循环参数用 Value 表达。
linalg 的结构化运算通用 tileUsingSCF → TilingInterface → Linalg 的实现；接口返回迭代域和分块后的操作。
llvm.add
MLIR 中的低层加法		ModuleTranslation → 方言翻译接口 → LLVM IRBuilder；输出真正的 LLVM IR。
